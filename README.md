# NEXORA – Car Rental Web Application (Frontend)

NEXORA is a frontend car rental web application built using HTML, CSS, and JavaScript.  
It allows users to browse cars, login, book cars, and apply as a host.

## Features
- Responsive and modern UI
- Car listing with images
- Login using localStorage
- Book a car (frontend flow)
- Become a host form
- Smooth animations

## Tech Stack
- HTML
- CSS
- JavaScript

## Note
This is a frontend-only project.
